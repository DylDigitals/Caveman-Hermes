# Contributing

Keep changes focused on communication guidance and its native Hermes delivery. Do not add provider proxies, output rewriting, extra inference, or Hermes core patches.

Read [INSTALL.md](INSTALL.md) and [verification](docs/VERIFICATION.md). Run the documented native test suite in disposable profile homes; never use real credentials for these tests. Include a focused regression for changed executable behavior and keep installation instructions accurate.

Contributions to this adapter are accepted under Apache-2.0. Preserve upstream notices and identify modifications to upstream material. Do not include credentials, personal sessions, private logs, or machine-specific deployment files.

This repository is independent of upstream Caveman. Submitting there is a separate action governed by its contribution policy and DCO requirements.
